# Liquid Glass 可读性规范与验证

本次保留珍珠白背景、薰衣草环境光、悬浮侧栏、开放内容区、列表布局、封面比例与生成逻辑、折射边缘和现有高光动画。没有增加依赖或动画。

## 统一规范

`src/tokens.css` 定义色板、语义和控件别名。`src/readability.css` 在原样式后加载，仅作用于主窗口和独立弹窗，覆盖窗口继续使用原有透明表面与 Canvas 渲染。

| 用途 | 颜色或字号 |
| --- | --- |
| 一级标题 | #30263A，34px / 700 |
| 分区标题 | #40344C，24px / 600 |
| 卡片曲名 | #40344C，19px / 600 |
| 正文、导航 | #5F536B，16px |
| 列表数据、按钮 | 15px |
| 次级信息、表头 | 14px |
| 英文装饰标签 | 12px / 600 |
| 次级文字 | #6B6075 |
| 强调文字 | #8056AC |
| 禁用文字 | #A49AAD |
| 分割线 | rgba(128,86,172,0.16) |

次级文字比建议的 #756A80 略深，保证其在浅紫色悬停表面上仍有至少 4.5:1 的计算对比度。普通文字不使用透明度；禁用状态使用明确颜色，而不是降低整个控件的 opacity。主按钮渐变最浅端为 #8962AF，与白色文字的计算对比度约 4.74:1。

玻璃透明度仅作用于材质背景。菜单使用更高不透明度和背景模糊，避免下面的列表文字干扰阅读。字体放大后，紧凑窗口允许必要换行，保持六列列表；菜单定位根据实际尺寸修正。长曲名保留完整 title 提示。

## 验证方式

先构建并打包当前应用，再运行：

```powershell
npm run check
npm run check:readability
npm run smoke -- --packaged
npm run smoke:ui -- --packaged
```

可读性脚本使用独立临时数据，不向正常曲库写入测试曲谱或校准值。它使用 Electron `--force-device-scale-factor` 模拟 100%、125%、150% DPI，在 1440×960 和 1040×720 逻辑窗口中检查字号、主要文字对比度和横向溢出，并截取曲库、校准、设置、MIDI 导入、演奏空间、菜单、重命名与英文界面。该检查不等同于在多台物理显示器上切换 Windows 系统缩放。

对比度检查采用 #EDE2F6 作为保守的浅紫色测试背景；它比常规白色玻璃表面更暗。脚本验证关键正文至少 4.5:1，不代表对每一个动态像素做了完整 WCAG 认证。

截图及机器报告保存在 `artifacts/readability/`。前后截图使用同一组测试曲谱和封面种子。`--before` 仅用于修改前采集基线。

现有回归另行验证 MIDI 解析与导入、播放暂停及进度、最小化继续运行、覆盖窗口真实透明像素、本地持久化、封面上传裁剪与备份恢复。原有音高校准参数保持手动实测。项目现有导入范围为 MIDI / DHScore，不新增音频识别功能。
