# Lavender Liquid Glass

本次在原 React / Electron 应用内升级；MIDI、映射、演奏时钟、窗口控制及 DHScore v1 结构沿用。曲库拆为独立 `LibraryPanel`，封面显示和编辑分别由 `CoverImage`、`CoverEditor` 承担。

## 设计变量

`src/tokens.css`：珍珠白 `#F9F7FC`、白 `#FFFFFF`、环境光 `#F3ECFA`、浅紫 `#E9DDF7`、薰衣草 `#C8A7EA`、强调紫 `#A77BD1`、深紫 `#8056AC`；主文字 `#302A36`、次要文字 `#82778C`。

主要圆角 22px，悬浮侧栏 27px，输入与按钮 11–12px。交互过渡 180ms，表面高光 22 秒低强度往返。支持 `prefers-reduced-motion`。主界面固定珍珠白 / 薰衣草语言；现有主题色与八轨颜色设置继续用于演奏画面。

## 材质层次

- 厚玻璃：方向不同的多层渐变、mask 细边折射、内部亮边 / 底部厚度阴影、悬浮投影、缓慢平移的表面高光。使用在最近曲谱卡、首次导入区、封面弹窗和菜单。
- 薄玻璃：克制的半透明白色、1px 亮边与低强度阴影，用于列表、设置和辅助区域。
- 正文、BPM、时间保持内容本身，没有逐项玻璃容器。
- 背景只提供极淡环境光；侧栏及底部演奏栏局部使用 backdrop blur。没有全屏实时位移滤镜，没有逐帧重建 SVG。

独立浮动侧栏与开放内容区保留曲库、演奏空间、偏好设置、使用指南入口。曲库顶部搜索与导入，最近演奏使用大艺术卡，全部曲谱使用紧凑列表。更多菜单支持键盘上下选择及 Escape；封面弹窗支持焦点范围与键盘裁剪参数。

## 本地艺术封面

`src/core/artwork.ts` 使用固定算法版本 1、128-bit 随机种子生成静态 SVG。构图由多层曲线丝带、透明渐变、镜面边线、局部高光及静态投影组成。颜色限定在珍珠白和紫色范围；没有文字、网络图片、AI 或歌曲特征输入。

新导入的曲谱自动保存独立种子。旧曲库首次升级时补齐并保存种子。重命名、演奏、搜索、刷新及重启都不会重新随机生成。显式“重新生成封面”才创建新种子；恢复自动封面使用自定义上传前保留的种子。

`CoverImage` 只在靠近视口时生成列表 SVG，浏览器异步解码，最多缓存 256 个封面来源。最近卡与编辑预览优先加载。种子生成及文件保存由主进程负责，渲染无持续滤镜动画。

自定义 PNG / JPEG / WebP 先本地解码和缩小预览，再通过等比正方形裁剪、平移、缩放确认。最终 512×512 PNG 写入 `data/covers/<sha256>.png`，通过受限的 `dha-cover://image/` 协议显示。协议不接受任意路径。替换不会删除用户选择的源图片。

元数据保存在本地曲库根级 `covers`，不向 `.dhscore` 增加封面字段。备份增加可选 `images`，包含实际图片字节；恢复检查摘要与图像尺寸。旧备份不含封面仍可恢复并自动补图。恢复前快照也包含封面。旧派生图片暂保留在数据目录，以保证历史快照可恢复。

## 验证与边界

单元测试覆盖 SVG 一致性 / 多样性、无远程内容、裁剪几何、旧库兼容及种子 / 自定义文件身份持久化；桌面测试覆盖上传、裁剪、恢复、重新生成、含图片备份、重启一致性。

检查 1040×720、1440×960、1920×1080 布局，以及 Electron 1.5 / 2 倍设备缩放。实际混合 DPI 多显示器及真实游戏性能仍需硬件实测。覆盖窗口独立保持透明，使用轻量 Canvas 玻璃与柔和紫色光效，仍以 60 FPS 为目标。

当前图片入口限制 20 MB / 4000 万像素，备份的自定义封面总字节限制 128 MB。超过限制有中文提示。SVG 属于程序化近似折射视觉，不是系统级物理光线追踪或对其他应用画面的折射。
