# Delta Harmonica Assistant

Windows 11 口琴 **MIDI 视觉辅助工具**。Lavender Liquid Glass：珍珠白与薰衣草液态玻璃界面，跟随 8 轨音符手动演奏。

保持 Electron + React + TypeScript + Vite 技术栈，基于已有主窗口、透明覆盖窗口、DHScore v1、本地存储逐步调整。完全本地运行，无账号、服务器、AI 模型或运行时联网需求。不读取游戏内存，不注入游戏，不模拟键盘或鼠标，不自动演奏，不播放音乐。

## 运行便携版

新版打开 `release/lavender/win-unpacked/Delta Harmonica Assistant.exe`。为保留旧版数据，本次使用独立输出目录，原 `release/win-unpacked/data` 不改动。需要继续使用旧曲库时，将旧版整个 `data` 文件夹复制到新版 EXE 同目录，或使用软件的备份恢复。整个 `win-unpacked` 文件夹一起移动或压缩分享，不能只复制 EXE；无需安装 Node.js 或 Python。请放在可写入的位置。曲谱与设置存储于 EXE 同目录的 `data/library.json`，封面图片位于 `data/covers`，运行缓存与日志位于 `data/runtime`。

1. 启动默认进入曲库，点击「导入曲谱」或拖入 `.mid`、`.midi`、`.dhscore`。
2. 多轨 MIDI 按单音比例、音区、轨道名自动推荐旋律轨道，可手动选择。打击乐不参与推荐；同轨和弦保留高声部，重复同键保留独立音符。
3. 在「偏好设置 → 游戏音高校准」填写**经过游戏实测**的 MIDI 音高和鼠标偏移。默认全部空白，不假定自然音阶、连续半音或鼠标偏移；无法确认的音符跳过。无可靠映射时禁止保存空曲谱。
4. 保存后点击曲谱的播放按钮，3 秒倒计时后跟随下落音符。鼠标提示 `L ↓ / M ± / R ↑` 与键盘同时按住到音符结束。
5. 默认鼠标穿透；在覆盖窗口设置关闭穿透后，拖动窗口顶部移动、拖右下角缩放。可锁定，或直接输入位置和尺寸。选用无边框游戏窗口；软件不会修改游戏设置。

无需校准即可点击「体验下落效果」查看明确标记的内置动画测试，或导入随包「测试曲谱」中的 `TEST_eight_lanes.dhscore`。测试数据不代表实测游戏音高。说明见 [fixtures/README.md](fixtures/README.md)。

## Lavender Liquid Glass 升级

- 独立浮动玻璃侧栏、开放式内容区、最近演奏艺术卡与紧凑曲谱列表，保留全部页面入口。
- 统一珍珠白 / 薰衣草 Design Tokens、多层折射亮边、玻璃厚度阴影、22 秒柔和流动高光、细腻按压与焦点反馈。
- 每首曲谱独立程序化 SVG 流体封面：首次创建并保存随机种子，重启保持一致；列表按视口延迟生成。
- 更多菜单支持重命名、导出、删除、更换 / 重新生成封面；支持 PNG、JPEG、WebP 自定义上传、正方形裁剪预览、缩放平移及恢复自动封面。
- 封面图片保存到数据目录，完整备份包含图片。DHScore v1 的音乐字段不变。
- 设计及数据规范见 [docs/LAVENDER-DESIGN.md](docs/LAVENDER-DESIGN.md)。

## 当前已实现

- 珍珠白薰衣草界面、曲库首页、中文 / English 切换、配置自动保存。
- MIDI Type 0/1、PPQ 解析：音高、Note On/Off、真实持续时间、变速和拍号变化。原始 MIDI 不写入曲库。
- 简单轨道选择、规则式高声部单音化、可靠映射计数和未映射跳过提示。八度折叠为可选项，默认关闭，只能折叠到已校准的同音名音高。
- 独立透明置顶覆盖窗口：8 条等宽轨道、玻璃渐变音符、霓虹拖尾、呼吸判定线、悬浮键帽；短音不拉长，连续同键不合并。
- 主题、轨道 / 音符颜色、背景 / 轨道 / 音符 / 判定线透明度；提前显示 0.5～3 秒，默认 2 秒。
- 开始、暂停、直接继续、重新开始、原曲时间进度跳转；超过 5 秒的长空白压缩，保留 0.25 秒尾部与 3 秒入场，保证最长提前时间。最后一个音符结束保留末帧。
- 统一时间基准与统一下落速度，动画目标 60 FPS；可见音符二分查找、时间轴缓存、DPI 渲染比例上限 2。主窗口最小化不阻塞覆盖层。
- 鼠标穿透、窗口拖动 / 缩放 / 锁定、显示器选择、保存位置；不跟随游戏位置 / 分辨率变化擅自重排。主窗口退出关闭覆盖窗口。
- 可选游戏窗口元数据检测（配置实际 EXE 名称后启用）：游戏所在显示器初始定位、失焦保持 / 隐藏 / 暂停、检测到游戏退出后关闭覆盖。使用 Windows 窗口及进程路径查询，不读取进程内存。
- 本地曲库搜索、创建 / 最近使用 / 名称排序、重命名、二次确认删除、自动保存、DHScore 导入导出、完整备份恢复。
- 版本化文件校验、原子持久化、中文错误提示及本地日志 `data/app.log`。损坏曲库保留原文件并提示，恢复备份前保存当前数据。
- Windows x64 便携目录打包；运行阶段不访问外部 HTTP / WebSocket，界面资源全部本地。

## 已移除

Spotify Basic Pitch、TensorFlow.js、模型下载 / 推理 Worker、CPU / GPU AI 设置、MP3 / WAV / FLAC / M4A 导入、FFmpeg 独立解码器、波形编辑、音频截取、云端识别入口。没有遗留识别页面或假识别结果。Electron 自带的媒体组件属于运行时，其存在不代表提供音频识别功能。

UI、MIDI、校验代码打包进产物，仅 `koffi` 作为外置原生运行依赖，发布包排除其他平台的原生二进制和构建源码。

## 开发与验证

所有依赖本地安装，无全局安装：

```powershell
npm ci
npm run dev
npm run check
npm run smoke
npm run smoke:ui
npm run package
npm run smoke -- --packaged
npm run smoke:ui -- --packaged
```

若 Electron 官方运行时下载中断，可运行 `node scripts/setup-electron.mjs`，或加 `--mirror` 使用镜像；两者都以 Electron 官方 npm 包内 SHA-256 校验，仅写入项目 `.cache` 与 `node_modules`。这只用于开发环境，不是产品的联网功能。

测试包括真实二进制 MIDI、多轨 / 打击乐排除、变速 / 拍号、延后首速度事件、短音与重复音、重叠单音化、未知音高过滤、鼠标保持、长空白压缩、暂停 / 末帧冻结、曲谱校验与本地保存。桌面回归用独立临时数据目录，验证实际文件导入、保存、倒计时、演奏控制、透明像素、最小化运行、导出、语言和持久化，不修改用户数据。

界面测试截图保存在 `artifacts/`。测试映射只存在测试环境，绝不自动应用为用户默认配置。

## 兼容性与待实测

- **准确游戏键位音高、鼠标偏移及连续鼠标保持的游戏实际释放规则尚待校准。** 当前不会凭空填入参数。
- 未在《三角洲行动》实际对局环境验证覆盖层、游戏权限差异、独占全屏限制或游戏帧率影响；请进行无边框模式实测。
- 多显示器选择、坐标持久化与高 DPI 逻辑已实现；仍需用 1080p / 2K / 4K 及混合缩放硬件验证。
- MIDI 主旋律选择是启发式规则，复杂编曲请手动选轨。弯音不转成鼠标滑音；延音踏板不延长 Note Off 时长，导入时明确提示。Type 2 / SMPTE 暂不支持。
- 不保证任意 MIDI 都能映射到尚未校准的 8 键。DHScore v1 继续兼容，新增可选 `timing` 仅用于变速节拍；详见 [docs/FORMAT.md](docs/FORMAT.md)。

模块：`src/core`（格式 / MIDI / 映射 / 时间轴）、`src/components`（界面 / Canvas）、`src/Overlay.tsx`（覆盖页）、`electron/main.ts`（窗口 / IPC）、`electron/storage.ts`（存储）、`electron/game.ts`（可选游戏检测）、`scripts`（开发 / 验证 / 打包）。
