# 明确标记的测试数据

这些文件用于验证软件，不是真实歌曲或已实测的游戏口琴音高。

- `TEST_eight_lanes.dhscore`：不依赖校准，可直接导入曲库。覆盖 8 轨道、短音、长音、连续同键、L/M/R 鼠标提示、连续鼠标保持及超过 5 秒空白。
- `TEST_neon_timing.mid`：真实标准 MIDI Type 1，含旋律、低音伴奏、打击乐，120 → 90 BPM 变速，4/4 → 3/4 拍号变化、和弦与长空白。

MIDI 自动测试采用**仅供测试的虚构映射** `[60,62,64,65,67,69,71,72]`，鼠标偏移 `left=-1, middle=+1, right=+12`。这组数值不代表游戏参数，不会写入软件默认设置，也不会自动应用到用户数据。实际导入 MIDI 前需要按游戏实测校准。

可运行 `node scripts/fixtures.mjs` 重新生成测试文件。
